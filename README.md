# 本Webアプリ
本Webアプリは一般の人が発疹が出た時に、病院に行く前に自分で診断できるようにひな形として制作したものです。背景として発疹はアトピー性皮膚炎やかぶれなどの湿疹以外にウイルス由来の発疹（帯状ほう疹、麻疹など）がありますが、一般の人はこの二つを区別できないことが多く、ウイルス由来の発疹だった場合に治療の開始が遅れて後遺症が残ってしまうケースがあるためです。方法はスマホで発疹の画像を撮り、アプリの問診票に症状を入力して写真と一緒に送信します。アプリは写真と症状から可能性の高い疾患名を通知します。アプリは初期段階なので、対象の疾患は、はしか、アトピー性皮膚炎、帯状ほう疹、手足口病、水ぼうそうの5種類にしました。

# 発疹画像分類の学習
5つの疾患（アトピー性皮膚炎、はしか、手足口病、水ぼうそう、帯状疱疹）の画像ファイルは、以下のリポジトリに入っています。[GitHubリポジトリを見る](https://github.com/Makoto-space/Photos-of-skin-diseases)　この5つのフォルダをColaboratoryのMyDrive/medical foldersに置いて学習させました。

# 発疹画像の適格性確認の学習
この学習の目的は、5つの疾患（アトピー性皮膚炎、はしか、手足口病、水ぼうそう、帯状疱疹）以外の画像が送信された場合は、「この画像は5つの疾患の典型的な発疹画像と異なるため、判定できない」という結果を返すことにあります。画像ファイルは、上記と同じリポジトリに入っています。[GitHubリポジトリを見る](https://github.com/Makoto-space/Photos-of-skin-diseases)　この5つのフォルダをColaboratoryのMyDrive/medical foldersに置いて学習させました。

# 症例テキスト分類の学習
5つの疾患（アトピー性皮膚炎、はしか、手足口病、水ぼうそう、帯状疱疹）の症例テキストは本リポジトリの症例テキストフォルダに入っています。5つのエクセルファイルをColaboratoryの/Contentフォルダに取り込んでから各100例の症例テキストを作成して学習に使用しました。

# ライブラリのバージョン
2025-5-1に動作確認したところ、エラーが出た（原因はnumpy2.0となり、np.Infがなくなってnp.infが使われるようになった）ため、numpy==1.25, pytorch_lightning==1.9.4に修正しました。

# main.py(FastAPI), app.py(streamlit)の動作確認
Visual Studio Codeで仮想環境を作成して、3つの学習済モデルをパソコンのフォルダに置いて、uvicornで動かしました。仮想環境にインストールされている全てのパッケージをrequirements.txtに記しました。
