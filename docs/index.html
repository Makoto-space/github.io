Skin Disease Candidate Suggestion Web App

Educational and research prototype using deep learning, skin images, and symptom information

皮膚画像と問診情報を用いて、可能性のある疾患カテゴリーを 提示する教育・研究目的のディープラーニング試作アプリです。

View Source Code

Project Overview

This project explores the use of deep learning models for analyzing skin images and symptom information.

皮膚疾患に関連する画像分類、画像品質確認、 問診テキスト解析を組み合わせた試作システムです。

Main Features

  • Skin-image input and preprocessing
  • Image-quality assessment
  • Deep-learning image classification
  • Symptom-text analysis
  • Candidate-category presentation

Technical Stack

  • Python
  • DenseNet201
  • AutoEncoder
  • BERT
  • Streamlit
  • FastAPI
  • Docker
  • Google Cloud Run

Project Status

This is an earlier portfolio project and is not currently under active development. It remains available as a record of my experience in medical AI application development.
